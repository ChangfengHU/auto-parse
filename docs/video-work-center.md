# 视频作品中心与抖音 MCP 0.2.0

入口：https://auto-parse-v2.vyibc.com/video-works 。与 /materials 解析素材库分开。

## 数据与恢复
- .data/video-work-center/deliveries 保存每个平台/账号/请求/模式的完整输入及回执；原片在 originals/<实际SHA256>.mp4，以字节内容去重，不转码，不受七天工作流缓存清理影响。
- 原件仅本机持久磁盘保存，不宣称异地备份。磁盘损坏仍可能丢失；不要将该目录当临时缓存删除。源CDN链接保留，失效时抖音/公众号可读取本地原片复用；公众号仍按100MiB/H264验证，不自动降质。
- 已准备不等于云草稿；draft_saved 要有原生保存与重新打开核对；published 仅真实创建回执，不代表审核通过或当前可见。
- 同请求改变元数据拒绝，未知结果不能换请求号重投。永久账本不是新的发布器，仍使用正式Supabase工作流。
- backfill CLI 仅读既有任务/公众号视频草稿账本；retain CLI 只下载所属CDN原视频并校验；均不发布。历史源不可用时明确未备份，不编造。
- MCP 新增 list_video_works、get_video_work（抖音范围）；get_video_task 对七天缓存未命中的任务回查永久档案，不执行任务。
- 原片每次上传前先留存。归档失败应停止新上传；发布回执另有旧去重账本保护。已有任务后续同步失败会记录告警，保留原任务便于恢复。

## 页面与权限
- 所有者2026-11-09明确要求直接查看：作品列表、详情、原片、封面无需安全连接，Fleet小工具“视频作品中心”直接打开 /video-works。不要重新增加查看登录表单。
- 只读GET和原片Range公开可读；准备/草稿POST及所有发布MCP认证保持不变。匿名查看不授予账号操作权限，抖音Token不能调用公众号。
- 页面支持搜索、筛选、分页、查看原片/平台时间线；普通查看者不显示账号操作表单。通过已授权MCP准备/保存草稿后自动留存。无公开发布按钮。
- 小红书已有原工作流，但作品中心转投尚未适配；X尚不支持视频；视频号未接入，不能标成已支持。
- 原素材管理和Fleet历史不删除、不隐藏。是否下架须另行验证。
