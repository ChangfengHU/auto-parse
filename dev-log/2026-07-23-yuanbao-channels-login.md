# API-001 自建腾讯元宝扫码登录与视频号取流

## 背景

视频号解析当前回退到 `sph.litao.workers.dev`。历史成功记录表明该服务曾返回视频流；2026-07-23 起该服务调用腾讯元宝 `get_parse_result` 时返回 HTTP 401，导致新请求只有封面和文字，没有视频。

## 目标

- 在 auto-parse 内维护独立腾讯元宝持久化浏览器会话。
- 提供受保护的扫码登录页面，不向前端或日志返回 Cookie。
- 视频号解析优先使用自有元宝会话，第三方接口仅作为临时回退。
- 扫码后用真实视频号链接验证视频流。

## 约束

- 元宝 Cookie、storage state 和管理员 Token 不进入 Git。
- 不修改或提交现有 `.materials.json` 工作区变更。
- 新登录态验证成功后才用于生产解析。
