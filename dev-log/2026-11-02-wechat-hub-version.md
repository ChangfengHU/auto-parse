# 公众号与自动发布插件：版本查询和扫码交接

用户要求符合Hub新自版本规范，并完善公众号浏览器发表/管理员扫码交接。Hub MCP 1.4.1公布1.4.0起所有入驻或更新MCP必须有get_version，插件内所有MCP也要符合；旧版本0.4.0已登记但不符合新规则。

本次对公众号、抖音、小红书、X四个现有平台端点统一新增只读get_version，分别0.4.1、0.1.1、0.1.1、0.1.1；从服务所在机器的部署记录返回release ID、构建Git提交、部署时间和中文变更，元数据缺失或版本不匹配时明确报告而不伪造。自动发布插件和Skill目标0.4.1。版本元数据不含凭据。

公众号原有流程支持按官方草稿ID、账号、指纹唯一核对后，保存AI声明并调用网页发表，管理员扫码需要保留同一浏览器会话；账本阻止未知结果重发。此次把84的VNC入口加入能力声明和启动回执。扫码后由原会话继续，最终微信应答、审核/公开可见分别核对。

历史仅验证到管理员扫码，未做真实最终提交。本次无用户指定的可发表稿件时不发表标注勿发布的测试稿；不得把代码路径和模拟测试当成真实发表验收。
