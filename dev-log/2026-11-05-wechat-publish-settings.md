# 微信公众号发表设置优化

实际服务为 0.5.4，运行时工具 28 个。源码已有 gh_ 原始 ID 校验的正确错误提示，以及留言默认开启。新增草稿作者缺省按账号名称、显式覆盖作者与留言关闭告警、submittedSettings 回显并声明未回读；版本接口增加工具清单 JSON SHA-256 和数量。账号默认名超 8 字则在网络请求之前拒绝，不静默截断。稳定请求指纹继续使用原请求，保持历史请求重放兼容。拟升版本 0.5.5。

60 项草稿和平台测试通过；这些是隔离网络模拟，不代表微信真实建稿验证。原创、个人观点声明、合集创建与发表时选择、真实 newspic 公开、原始配置回读与锁诊断尚未实现。当前发现已有等待管理员扫码的活动发表会话，不能中断，生产尚未部署、Hub 尚未更新。
