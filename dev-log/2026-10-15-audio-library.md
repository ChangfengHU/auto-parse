# AUDIO-001 音频素材搜索页面与统一检索接口

## 目标

- 新增独立音频素材页面，首期覆盖背景音乐与音效搜索。
- 支持类型切换、关键词与常用场景筛选、在线播放、素材详情和授权来源查看。
- 先定义稳定的站内 API 数据结构，为后续 `music_search`、`sound_effect_search` MCP 工具复用。
- 本期不实现视频混音、渲染任务或生成式音乐。

## 约束

- 保持现有 doouyin 导航和视觉体系。
- 不改动工作区内已有的 `.materials.json` 修改。
- 外部素材必须显示来源、作者和许可证，不能把“可检索”表述为“可任意商用”。

## 实现边界

- 页面只负责检索、筛选、试听、复制地址和跳转授权原页，不代理下载，也不承诺素材可无条件商用。
- 站内接口的 `AudioAsset` 返回模型可直接作为后续 MCP 的基础；MCP 服务、混音、渲染状态和生成式音频不在本期范围。
